SynaptoSnap icons

Draws every icon file the app uses from one design. The design shows a synaptonemal complex: two homologous axes (teal and magenta) zipped together by transverse filaments, inside camera viewfinder corners. From 56 px up it is the vector drawing below (also saved as icon.svg). From 16 to 48 px it is a pixel-snapped straight version, so that taskbar and tab sizes stay sharp. Click a link to save a file, and put it at the path shown (relative to the app folder).
